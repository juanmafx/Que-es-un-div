What Is a div?

A div is a generic block-level container in an HTML document. It carries no meaning of its own, so it is used to group content for styling and layout.

The essentials

  • A div opens with <div> and closes with </div>.
  • A div can contain other divs.
  • CSS targets a div through its class or id attribute.
  • A div can have many classes but only one id, and that id must be unique in the document.
  • When a semantic element such as <nav> or <article> fits the content, prefer it over a div.
