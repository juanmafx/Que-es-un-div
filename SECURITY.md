# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 1.x | Yes |
| Earlier unversioned code | No |

## Reporting a vulnerability

Please report privately through GitHub's **Report a vulnerability** option on the repository's Security tab, if it is enabled. If it is not, open an issue that asks for a private contact channel and leave out the technical details.

This is a personal educational project, so responses are best effort and no response time is promised.

## Scope

The project is a static page with no backend, accounts, cookies or stored user data. Relevant reports include script injection in the tag checker, weaknesses in the content security policy, and vulnerable development dependencies.

See [docs/SECURITY_AUDIT.md](docs/SECURITY_AUDIT.md) for the latest audit.
